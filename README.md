# Growing Everyday field guides

Pick a job you need to do this week. Each guide includes an editable worksheet and a fictional example you can test before using the method with your team.

| Job | Start here | What you can check |
| --- | --- | --- |
| Turn an SEO finding into a repair someone can verify | [SEO audit and repair kit](seo-audit/README.md) | Trace a broken booking link from the visitor’s click to the ticket and the repaired page. |
| Get a new inquiry to the person on duty | [Lead handoff playbook](lead-handoff/README.md) | Replay a duplicate event or take the primary owner off duty and see who owes the next reply. |

If a worksheet misses an edge case, describe the steps and expected outcome using made-up records. Keep customer data and production URLs out of public issues.
